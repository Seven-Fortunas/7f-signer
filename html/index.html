7F Signer

From device To device

Point the camera at the device's QR. Saves what the device exports: <ski>.vk, root-<ski>.pem, <ski>.genesis, <ski>.devfund, deputy-<ski>.pem.

How the ids below are derived: pin = SHA-256 of the raw vk bytes (hex-decoded, not the hex text), 64 hex; subject key id = the first 20 bytes of that hash (the pin's first 40 hex), RFC 7093 method 1. Same values sf-wallet-gov prints.

Pick the file the device must scan: genesis-unsigned.json, devfund-unsigned.json, root-<ski>.pem or a Deputy CSR .pem. Nothing is uploaded; the file stays in this browser.

Version . Runs entirely in this browser; nothing is sent anywhere.
